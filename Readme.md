# Drift-Away

*Write it. Free it. Watch it disappear.*

**Drift-Away** is a calming, browser-based space made for letting go of your thoughts. Type whatever is on your mind, pick a mood and style, and release it into a Minecraft-inspired sky where it gently drifts, bounces around, and fades away over time.

🔗 **Live Demo:** [drift-away-eight.vercel.app](https://drift-away-eight.vercel.app/)

## Features

* **Four Note Styles:** Release your thoughts as a floating cloud sign, a book, a glowing flickering torch, or a message in a bottle.
* **Moods & Colors:** Choose from 8 colors (or let it pick randomly) and set a mood—Happy, Sad, Angry, or Calm—which changes how your note moves and behaves in the sky.
* **Three Worlds:** Switch between the **Overworld** (with a smooth day/night cycle, drifting clouds, sun, moon, and stars), the **Nether** (deep red sky with rising embers), and **The End** (a dark, starry void).
* **Pin & Save:** Click any floating note to pin it so it doesn't fade away, or export your entire sky as a `.png` image to keep the moment.
* **Custom Controls & Retro Audio:** Tweak drift speed, note lifetime, and 8-bit Web Audio sound effects right from the settings menu. Everything saves automatically to your browser's local storage.

## Controls & Shortcuts

* **Enter:** Release your note into the sky.
* **Hover over a note:** Pause its movement and see when it was released.
* **Click a note:** Pin or unpin it.
* **Esc:** Clear the text input, or clear all unpinned notes from the sky.
* **Alt + 1–8:** Quick-select a note color (`Alt + 0` sets it back to random).

## Tech Stack & Deployment

Built with plain HTML, CSS, and vanilla JavaScript—no frameworks or build steps required.

* **Live Hosting:** Deployed as a static site on [Vercel](https://drift-away-eight.vercel.app/).
* **Run Locally:** Clone the repo, make sure `index.html`, `style.css`, and `script.js` are in the same folder, and open `index.html` in any browser.
